# File index

A map of the repository. The approved design at `docs/design.md` is the canonical implementation contract. Generated files are marked; regenerate them with `make manifests generate` instead of editing them.

## Source

- `cmd/main.go` — manager entry point (scheme, metrics, probes, leader election, controller registration)
- `api/v1alpha1/storagerequest_types.go` — `StorageRequest` API types, identity markers, finalizer, condition types and reasons
- `api/v1alpha1/validation.go` — defensive Go validation of the spec
- `api/v1alpha1/groupversion_info.go` — API group registration
- `api/v1alpha1/zz_generated.deepcopy.go` — generated
- `internal/controller/storagerequest_controller.go` — reconciliation logic (create, identity, status, resize)
- `internal/controller/finalize.go` — Retain/Delete finalization behind the finalizer
- `internal/storage/pvc_builder.go` — deterministic desired-PVC builder
- `internal/storage/identity.go` — request-UID and PVC-UID identity check
- `internal/storage/resize.go` — PVC resize-state observation and the grow-only resize plan
- `internal/storage/pvc_validation.go` — immutable-field comparison of a request against its claim
- `internal/conditions/conditions.go` — Ready/Degraded assessment and status projection of a verified PVC

## Tests
