# Support

This project is in the implementation phase; no production support commitment or supported release matrix has been published.

- **Design and API questions:** read [`docs/design.md`](docs/design.md), then open a GitHub issue with the `design` or `api` label.
- **Implementation bugs:** open a bug report with Kubernetes version, operator commit, relevant StorageClass/CSI details, sanitized controller events/logs, and reproducible steps.
- **Feature proposals:** explain the use case, why it belongs in the v1 scope, API impact, failure modes, data-loss implications, and testing needs.
- **Security vulnerabilities:** follow [`SECURITY.md`](SECURITY.md); do not file a public issue.

Do not include secrets, kubeconfig contents, customer data, or private backend details in issues.
